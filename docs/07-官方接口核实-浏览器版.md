# 得物开放平台官方接口核实（2026-10-22 浏览器读取公开文档）
网关：生产 https://openapi.dewu.com ，沙箱 https://openapi-sandbox.dewu.com ，路径 /dop/api/v1/...，HTTPS+UTF-8+JSON。
公共参数：app_key, timestamp(ms), sign 必填；access_token 仅 ISV 必填（自研商家应用不需要）。
签名：参数加 app_key、timestamp；去掉 null（新版文档保留空串），不含 secret；key 字典序；key 和 value 按 Java URLEncoder 编码（空格->+，*不变，~->%7E）；拼 k=v&k=v，末尾直接拼 app_secret（不编码）；UTF-8 MD5 转大写。数组按逗号拼接元素；对象为 key 排序后的紧凑 JSON。文档 https://open.dewu.com/#/doc?id=1016729196&pid=1010515087&type=article
应用类型：自研企业商家=1应用1店铺，无需OAuth；ISV 最多3个应用，经服务市场 OAuth。多店铺 => 每店一个自研应用凭据，或 ISV+OAuth。
OAuth(ISV)：code -> POST https://open.dewu.com/api/v1/h5/passport/v1/oauth2/token {client_id, client_secret, authorization_code} -> access_token, refresh_token, open_id, 过期时间；刷新 POST .../oauth2/refresh_token {client_id, client_secret, refresh_token}。access_token 约24h（文档示例与说明不一致），refresh_token 约半年。
接口须申请权限包（应用详情->API权限包），1-3 个工作日审核。
出价列表：GET /dop/api/v1/bidding/normal/normal_list（sku_id, spu_id, merchant_sku_code, start_modified/end_modified 窗口≤60天, page_no, page_size≤30）-> biddings[]{sku_id, price(分), bidding_no, qty, qty_remain, qty_sold, bidding_type}
通用列表：POST /dop/api/v1/bidding/generic_list，bidding_type 必填（0普通现货,1普通预售,3跨境,6入仓,7极速现货,8极速预售,12/13品牌专供,14品牌直发,15虚拟,23保税,25跨境寄售），sku_ids≤20, page_size≤30
详情：POST /dop/api/v1/bidding/generic_detail {bidding_no}
商品池（未核实参数）：POST /dop/api/v1/product_pool/list ；SPU 归平台所有，商家只拥有出价。
改价(普通现货)：POST /dop/api/v1/bidding/normal/normal_update 必填 bidding_no, price(分，须以900结尾，如19900), qty≥1, old_qty；可选 after_sale_type, support_cancel_to_warehouse, trans_mfs。数量不能改为0。每次修改后 bidding_no 会变，必须保存返回的新单号。
通用改价：POST /dop/api/v1/bidding/general/update_bidding 必填 bidding_no, price；可选 qty, old_qty, after_sale_type, address_id, inventory_list（类型6/13/3/23/25时必填）等 -> {bidding_no, qty, tips, risk_toast, bid_status}
最低价（只有解决方案文档里的路径，参数未核实，额度按出价量和订单量动态分配）：普通现货 /dop/api/v1/bidding/normal/normal_lowest_price；极速现货 /dop/api/v1/bidding/fast/fast_lowest_price；预售 /dop/api/v1/bidding/normal_pre_sale/lowest_price；品牌专供 /dop/api/v1/bidding/brand/brand_lowest_price；寄售/入仓 /dop/api/v1/consign/bidding/lowest_price；跨境 /dop/api/v1/bidding/oversea/oversea_lowest_price
官方自动跟价：POST /dop/api/v1/bidding/add_auto_bidding {bidding_no, min_price, type(1=跟平台最低,2=比平台最低低一档), auto_switch}；列表 POST /dop/api/v1/bidding/auto_bidding/list {spu_ids≤100}；详情 POST /dop/api/v1/bidding/auto_bidding/detail {bidding_no}
限流：每个接口默认每天 2 万次、每分钟 1000 次；每个 app_key 总量 1800 万次；超限返回 {"code":5030}；用到 80% 时短信预警；提额发邮件到 open-product@shizhuang-inc.com
