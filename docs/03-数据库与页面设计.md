# 数据库与页面设计

迁移：`backend/src/main/resources/db/migration/V1__init.sql`。金额统一 BIGINT（分）。

| 表 | 说明 | 关键约束/索引 |
|---|---|---|
| shops / shop_groups | 店铺、分组、经营主体、扫描间隔、QPS | UK(platform, external_shop_id) |
| shop_authorizations | 授权状态与 token（*_enc 需加密） | UK(shop_id, auth_type)，IDX(status, expires_at) |
| app_users / user_shop_permissions | 用户与店铺权限隔离 | PK(user_id, shop_id) |
| products / product_skus | 商品与 SKU | UK(platform, spu_id)、UK(sku_id) |
| shop_sku_listings | SKU-店铺映射（出价），排除标记、SKU 利润底线、异常标记、乐观锁 version | UK(shop_id, sku_pk)、UK(shop_id, external_listing_id) |
| sku_costs | 成本（店铺级或全局），按生效时间取最新 | IDX(sku_pk, shop_id, effective_from) |
| pricing_strategies / strategy_assignments | 策略及 SHOP/PRODUCT/LISTING 三级分配 | UK(shop_id, scope, target_id) |
| competitor_price_snapshots | 竞争价快照（是否同主体） | IDX(sku_pk, captured_at) |
| repricing_tasks / repricing_task_items | 任务与明细 | **幂等键** UK(idempotency_key)，UK(task_id, listing_id) |
| repricing_history | 改价历史（目标价、回查价） | IDX(listing_id, created_at) |
| api_call_logs / audit_logs | 接口调用与操作审计 | 时间倒序索引 |
| system_switches | 全局跟价、紧急停止 | — |

10 万 SKU 规模：查询均按 shop_id 过滤并有索引；快照/日志表建议按月分区并设置保留期（后续迁移 V2）。

## 页面
经营总览（指标、全局暂停/恢复/紧急停止、授权告警）· 店铺管理 · SKU 列表（多维筛选、批量编辑、成本导入、批量调价）· 异常商品 · 规则配置（策略+分配）· 任务记录（明细抽屉）· 价格历史 · 接口与审计日志。
