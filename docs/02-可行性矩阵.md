# 可行性矩阵

| 能力 | 适配层方法 | 官方接口 | 所需权限/前提 | 当前状态 |
|---|---|---|---|---|
| 店铺授权 | authorizeShop | 开放平台 OAuth2（应用审核后） | 开发者入驻 + 应用 + 商家授权 | 骨架，待接入 |
| 商品/SKU 同步 | listProducts | 推测有（商品类 API） | 商品读权限 | 待核实 |
| 出价/在售同步 | listSkuListings | 推测有（出价列表） | 出价读权限 | 待核实 |
| 当前报价 | getCurrentPrice | 依赖出价查询 | 同上 | 待核实 |
| 竞争最低价 | getCompetitorPrice | **未确认** | 市场/价格查询权限 | 未确认则不可跟价 |
| 修改出价价格 | updateListingPrice | **未确认** | 出价写权限 | 未确认则只能 DRY-RUN |
| 平台自动跟价 | enablePlatformAutoFollow | **未确认** | — | 返回 false |
| 改价结果回查 | getUpdateResult | 未确认（可退化为再次查询报价） | 出价读权限 | 已实现退化逻辑 |
| 采购成本/利润 | 本地 | 不需要 | — | ✅ 已实现（Excel） |
| 跟价策略/风控/任务 | 本地 | 不需要 | — | ✅ 已实现（Mock 验证） |

**禁止**：商家后台/App 私有接口、抓包签名、模拟 App/浏览器、共享 Cookie。
