# 得物开放平台真实适配器实现说明

> 状态：已实现 + WireMock 契约测试通过；**未用真实凭据联调**；**不得宣称可正常自动改价**。

## 代码位置
`backend/src/main/java/com/dewu/repricer/adapter/dewu/`
- `DewuSigner`：签名（字典序、Java URLEncoder、去 null 保留空串、数组逗号拼接、对象 key 排序紧凑 JSON、末尾拼 app_secret、MD5 大写）。
- `DewuHttpClient`：生产 `https://openapi.dewu.com` / 沙箱 `https://openapi-sandbox.dewu.com`（`DEWU_ENV`）；GET 参数放 query，POST 参数放 JSON body；错误码映射。
- `DewuOpenPlatformAdapter`：接口映射、token 自动刷新、能力声明。
- `JdbcDewuCredentialStore` + `security/CryptoService`：凭据 AES-256-GCM 加密存储（`REPRICER_CRYPTO_KEY`）。
- `JdbcQuotaTracker`：按“店铺 + 接口”记录每分钟 / 每日调用量（表 `api_call_counters`），超限本地拒绝（可重试）。

## 错误处理
| 情况 | 映射 | 执行器行为 |
|---|---|---|
| code 5030（可配 `rate-limit-codes`）、HTTP 429/5xx、网络错误 | 可重试 | 指数退避重新入队 |
| 本地配额超限（默认 1000/分钟、20000/天，可配） | LOCAL_QUOTA，可重试 | 退避 |
| token 失效码（`token-expired-codes`，**待核实，默认空**）或 HTTP 401 | ISV 模式自动刷新后重试一次 | — |
| 其他业务错误 | 不可重试 | FAILED 并计入店铺熔断 |

## 改价流程
1. 校验权限包 BIDDING_WRITE；校验价格（分）`% 1000 == 900`。
2. `generic_detail` 读取当前价与剩余数量；已是目标价 → 直接成功（幂等）。
3. 类型 0：`normal_update`（qty = old_qty = 剩余数量，剩余为 0 时跳过）；其他：`general/update_bidding`。
4. 保存响应中的新 `bidding_no`（写回 `shop_sku_listings.external_listing_id`），再用新单号 `generic_detail` 回查实际价格，不一致标记异常。
引擎在策略 `price_rule=DEWU_900` 时，所有取整（目标价、利润底价、最高售价）都落在 x900 上。
