# 小规模真实改价测试方案（接入官方接口后执行）

前置：开放平台应用审核通过、相应权限包已授予、商家书面同意；DewuOpenPlatformAdapter 按控制台文档实现并通过契约测试；capabilities 仅打开已核实项。

1. **只读阶段（≥3 天）**：开启同步与查价，DRY-RUN=true，对比系统目标价与人工判断，核对费用计算与实际结算单。
2. **单店单 SKU**：选 1 个低价值、库存 1 的 SKU，策略设置最高/最低售价窄区间、max_change_ratio=0.05；手动创建非模拟任务，核对回查价与商家后台一致。
3. **扩大到 10~50 SKU**，单店，手动触发，观察 api_call_logs 错误率、限流、熔断。
4. **开启定时**：扫描间隔从 30 分钟起，逐步缩短，确认额度余量 ≥ 30%。
5. **多店铺**：验证同主体防互压、权限隔离。
每一步的退出条件：出现回查不一致、错误率 > 2%、任何越界价格 → 立即紧急停止并复盘。
回滚：紧急停止 → 根据 repricing_history 的 old_price 人工恢复。
