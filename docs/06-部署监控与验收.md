# 部署、日志、监控与验收

## 部署
`cp .env.example .env && docker compose up -d --build`。服务：postgres、redis、backend(宿主 18080→8080)、frontend(宿主 18081→80)、prometheus(9090)。Flyway 启动时自动迁移。密钥只放 .env/密钥管理，不入库不入仓。

## 日志与监控
- 日志带 `traceTask` (MDC taskId)；接口调用写 api_call_logs；所有操作写 audit_logs。
- Actuator：`/actuator/health`、`/actuator/prometheus`。自定义指标：`repricer_decisions_total{action}`、`repricer_price_updated_total`、`repricer_queue_size`。
- 建议告警：队列积压、API 错误率、授权 EXPIRING/EXPIRED、BLOCKED 激增。
